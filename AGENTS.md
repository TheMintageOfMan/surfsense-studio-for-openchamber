# Project guidance

Read `SPEC.md`, `README.md`, and `nextsteps.md` first; `nextsteps.md` holds the current plan and working setup. This is an independently distributed, optional extension, not part of OpenChamber's setup. Preserve `windows-11-x64/` and `linux-fedora-amd64/`; edit shared source in `shared/` and rebuild with `npm run build`. Only Summary, Flashcards, Quiz, Mind map, and Web page are implemented; the other 7 formats appear as disabled grid tiles with no implementation. Document formats must use JavaScript builders in the service: no self-packaged Python. Password-protected, remote, and relay hosts are out of scope. Distinguish controlled tests from live model verification and untested platform builds. Do not weaken authentication, silently substitute models, truncate sources, or copy generated-code execution from upstream. Keep scratch work under `temp/` and generated history under `.studio/`, both out of commits.
