# Project guidance

Read `SPEC.md` and `README.md` first. This is an independently distributed, optional extension, not part of OpenChamber's setup. Preserve `windows-11-x64/` and `linux-fedora-amd64/`; edit shared source in `shared/` and rebuild with `npm run build`. Only Summary is implemented in this first pass. Distinguish controlled tests from live model verification and untested platform builds. Do not weaken authentication, silently substitute models, truncate sources, or copy generated-code execution from upstream. Keep scratch work under `temp/` and generated history under `.studio/`, both out of commits.
