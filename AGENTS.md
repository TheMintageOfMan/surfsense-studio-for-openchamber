# Project guidance

Read `SPEC.md`, `README.md`, and `nextsteps.md` first; `nextsteps.md` holds the current plan and working setup. This is an independently distributed, optional extension, not part of OpenChamber's setup. Preserve `windows-11-x64/` and `linux-fedora-amd64/`; edit shared source in `shared/` and rebuild with `npm run build`. Ten formats are implemented; Podcast and Picture appear as disabled grid tiles with no implementation. Infographic is drawn by AntV Infographic in a worker thread (`shared/service/builders/infographic*.mjs`) from a checked layout allowlist in `shared/common/infographic.mjs`; add a layout only after rendering it and checking every field shows. Inter (`shared/common/font.mjs`, `shared/fonts/`) is the one font for every surface; regenerate `Inter-metrics.json` with `node scripts/font-metrics.mjs` if the font files change. Sources are read by the service, never the panel (`shared/service/sources.mjs`, types in `shared/common/sources.mjs`); old `.doc`/`.xls`/`.ppt` files are read by Studio's own Compound File Binary reader in `shared/service/legacy*.mjs`; the current chat comes from `shared/service/chat.mjs` and is compressed by OpenCode above 10,000 characters. Document formats (Word, Slides, Spreadsheet, PDF) are validated in `shared/common/documents.mjs` and built by Node-only JavaScript builders in `shared/service/builders/`: no self-packaged Python, and the panel never imports the builders. Every bundled package and font needs license text; the build fails otherwise (vendored notices live in `shared/licenses/`). Password-protected, remote, and relay hosts are out of scope. Distinguish controlled tests from live model verification and untested platform builds. The panel targets non-technical users (age 10 and up): pick sources, tap a tile, open, and save, with defaults chosen automatically and technical detail only under **About this**. Quiet recovery is limited to the retry budget in `shared/service/jobs.mjs`: three text-model calls per request, every one recorded. Do not weaken authentication, truncate sources, or copy generated-code execution from upstream. Keep scratch work under `temp/` and generated history under `.studio/`, both out of commits.
